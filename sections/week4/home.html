We’ll first estimate a simple one-dimensional CFA.

Calculate the following quantities for the Warmth CFA described above.

  1. How many parameters does the model contain?
  2. How many pieces of information do the data provide?
  3. How many parameters will we estimate after applying the necessary scaling constraints?
  4. How many degrees of freedom will our estimated model have?
Click to show code
  1. The model contains 21 parameters
    • 10 factor loadings
    • 10 residual variances
    • One latent variance
  2. We have 10 observed variables, so the data provide 10 (10 + 1) / 2 = 55 pieces of information.
  3. To identify the covariance structure model, we need to fix one parameter. So we will estimate 20 parameters.
  4. The estimated model will have 55 - 20 = 35 degrees of freedom.

Define the lavaan model syntax for a unidimensional CFA of the Warmth scale.

  • Do not specify any mean structure.
  • Save this model syntax as an object in your environment.
Click to show code 
mod1 <- '
warmth =~ A1 + A2 + A3 + A4 + A5 + A6 + A7 + A8 + A9 + A10
'

The cfa() function is just a wrapper for the lavaan() function with several options set at the defaults you would want for a standard CFA.

  • By default, the model is identified by fixing the first factor loading of each factor to 1 (due to the argument auto.fix.first = TRUE).

To see a full list of the (many) options you can specify to tweak the behavior of lavaan estimation functions run ?lavOptions.

The estimated latent variance is \(\psi_{11} = 0.545\).
